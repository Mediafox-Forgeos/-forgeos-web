## Recommendation

**GO_WITH_MANUAL_PROCESSES.**

The operational loop itself — the software this pilot exists to test — is real, tested three times over (unit, real-database e2e, and live two-browser-session validation), and reached `PILOT_READY` on its own merits in `docs/product/OPERATIONAL_LOOP_PILOT_READINESS.md`. Nothing in this discovery pass found a reason to revisit that verdict for the loop as software. What this pass found is that **operating** it for a real pilot requires a defined set of one-time, human, out-of-product steps — none of which are missing capabilities the pilot cannot credibly proceed without, all of which are named below with an owner.

No new product work is recommended. No risk in `PILOT_RISK_REGISTER.md` blocks the pilot's required scope.

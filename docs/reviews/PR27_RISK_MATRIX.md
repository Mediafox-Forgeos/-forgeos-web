## Reading this matrix

No fix is proposed, scheduled, or implied by any row above — this document is informational, per WO-ARGOS-011A's review-only mandate. Every finding here is either an explicit, already-documented limitation of CAP-005 re-examined through a concurrency/scale lens (R-03, R-07, R-12), or a new finding produced specifically by reasoning about interleaved/concurrent execution the existing test suite does not exercise (R-01, R-06, R-08, R-09, R-11, R-13). None were found by running a failing test — the entire test suite for this PR passes, because it never exercises true concurrency.
